# HUD Tuner

HUD Tuner lets you decide what stays on screen in World of Warcraft: Forever.

- Group action bars and choose when each group appears.
- Replace the default player and target frames with compact class icons.
- Show FPS and home or world latency in a movable display.
- Hide or restore Blizzard's objective tracker from the **Quests** tab.

## Compatibility and installation

Built for **WoW Forever 1.60.1** (interface 16001). Download the release from [CurseForge](https://www.curseforge.com/wow/addons/hud-tuner), or copy all addon files (.lua and .toc) into a folder named **ForeverHoverBars** under the Forever client's **Interface/AddOns** directory.

Use **/foreverhud**, **/fhb**, or the minimap button to open settings. The interface follows the WoW client language. Spanish clients use Spanish, and English is the fallback for all other languages. Preferences are saved per character.

WoW identifies the addon folder as **ForeverHoverBars**.
