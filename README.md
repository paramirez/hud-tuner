# HUD Tuner

HUD Tuner lets you decide what stays on screen in World of Warcraft: Forever.

- Name action-bar groups, preview bars in the HUD, and undo moves between groups or group deletions.
- Replace the player and target frames independently with compact, clickable bars. Choose their size, visibility, and text format. Color health by class, unit reaction, or remaining health, or pick a fixed color.
- Preview each bar in **Unit frames**, then click it to edit. Try different target and casting examples before placing a frame in the HUD.
- Show FPS and home or world latency in a movable display.
- Open **Edit HUD** to place the unit frames and performance display with to-scale previews and alignment guides.
- Under **Settings → General**, toggle the minimap button or Blizzard's objective tracker.
- Under **Settings → Profiles**, copy settings from another character. Log in and out on the source character first.

## Compatibility and installation

Built for **WoW Forever 1.60.1** (interface 16001). Download the release from [CurseForge](https://www.curseforge.com/wow/addons/hud-tuner), or copy all addon files (.lua and .toc) into a folder named **ForeverHoverBars** under the Forever client's **Interface/AddOns** directory.

Use **/foreverhud**, **/fhb**, or the minimap button to open settings. The interface follows the WoW client language. Spanish clients use Spanish, and English is the fallback for all other languages. Preferences are saved per character.

WoW identifies the addon folder as **ForeverHoverBars**.
