# HUD Tuner

HUD Tuner lets you decide what stays on screen in World of Warcraft: Forever.

- Group action bars and choose when each group appears.
- Replace the default player and target frames with compact class icons.
- Show FPS and home or world latency in a movable display.
- Hide or restore Blizzard's objective tracker from the **Misiones** tab.

## Compatibility and installation

Built for **WoW Forever 1.60.1** (interface 16001). Download the release from [CurseForge](https://www.curseforge.com/wow/addons/hud-tuner), or copy the two addon files into a folder named **ForeverHoverBars** under the Forever client's **Interface/AddOns** directory.

Use **/foreverhud**, **/fhb**, or the minimap button to open settings. The in-game panel is in Spanish and preferences are saved per character.

The repository contains the source for version 2.8. WoW identifies the addon folder as **ForeverHoverBars**.
